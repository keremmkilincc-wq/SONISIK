## 🎮 Konsept
Elektrik kesildi. Tek ışığın el fenerin. Pil %100'den geriye sayıyor. Karanlık evde anahtarları topla, yaratığa yakalanmadan çıkış kapısını bul.

## 🚀 Çalıştır
```bash
# Tarayıcıda
python -m http.server 8000
# -> http://localhost:8000
```
